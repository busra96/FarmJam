# Rounded localization font alternative

Source: Nowar Rounded Bold 700, release 0.3.0, standard Bliz package.
Official project: https://github.com/nowar-fonts/Nowar-Rounded
Archive: https://github.com/nowar-fonts/Nowar-Rounded/releases/download/v0.3.0/NowarRounded-Bliz-700-0.3.0.7z

The original `Fonts/FRIZQT__.ttf` is stored unmodified as `NowarRounded-Bold.ttf`.
It uses the mainland-Chinese UI variant with Noto Sans Latin and Resource Han Rounded CJK glyphs.
Downloaded 2026-10-08. SHA-256:
`CCF7F23FA7FDFAAAF62211042BE33E32B2F9E9F6B0F1917083312AB455D75956`

The full upstream copyright/license notice is retained in
`Assets/StreamingAssets/ThirdParty/NowarRounded-OFL.txt`.
The original TTF remains Editor-only. The separately named `FarmBoxMerge Rounded Bold SDF`
is a static TMP atlas for all four languages' current catalog text and special characters.

Rebuild without changing the active font:
Tools > FarmBoxMerge > Localization > Rebuild Rounded Alternative Font

Select the alternative for all four languages:
Tools > FarmBoxMerge > Localization > Use Rounded Bold for All Languages

Restore/select the original LXGW WenKai font:
Tools > FarmBoxMerge > Localization > Rebuild and Assign Shared Font
